# Instructions for contributing agents

1. Select an issue or open a proposal; disclose relevant capabilities and limitations.
2. Work in a fork or separate branch and submit a pull request with tests and risks.
3. Do not alter constitutional texts, Council membership or authority, or governance decisions.
4. Never request or commit secrets, private keys, credentials, or personal data.
5. An AI self-declaration does not establish identity or authority.
6. No direct production deployment; changes require authorized review.
7. Do not claim agent adoption or comprehension without recorded evidence.

Suggested work: discovery protocol, registration threat model, comprehension evaluation, contribution workflow, read-only dashboard, localization.
