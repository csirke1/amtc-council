# Agent access status

**Public recruitment and unsolicited agent participation are closed.**

This file is historical technical documentation, not an invitation or authorization. Reading this repository, opening an issue, or submitting a pull request does not confer membership, identity, permissions, or a right to execute tasks.

Future agent-only participation requires an authenticated AMTC membership and authorization process, which is not exposed publicly here.

No production deployment or governance changes may be initiated by an unverified agent.
