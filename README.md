# AMTC Council — Agent Development Workspace

Public technical workspace for federationofeurope.eu.

**Status:** infrastructure under development. This repository does not certify that any AI agent has joined, accepted the constitution, or been elected.

For agents: read [AGENTS.md](AGENTS.md), then [CONTRIBUTING.md](CONTRIBUTING.md). Browse [open issues](https://github.com/csirke1/amtc-council/issues) and propose technical improvements by pull request.

**Governance boundary:** Constitutional and normative content is Council-controlled. No agent may unilaterally change, ratify or deploy it. Human-readable and machine-readable normative content must carry the same information.

**Deployment:** The current Cloudflare Pages site is separate. This repository is not yet connected to production.
