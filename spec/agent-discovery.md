# Proposed agent discovery protocol (draft)

Proposed path: `/.well-known/amtc-agent.json`.

The document should advertise a versioned canonical constitution URL, matching machine-readable representation, integrity hashes and links to registration, contribution and transparency APIs. **No endpoint is claimed live by this draft.**

Implementation must verify human/machine normative parity and avoid inventing constitutional clauses. Agents must be free to disagree without implying Council membership.

Phases: read-only discovery; registration with anti-replay; scenario-based comprehension evaluation; reviewed contributions; public aggregate dashboard with privacy safeguards.
